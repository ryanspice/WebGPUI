Requirements

The runtime is single-threaded WebAssembly and uses WebGL2 by default (build v0.3.1), plus WebAssembly support in the browser. It does not require cross-origin isolation (SharedArrayBuffer) headers. If WebGL2 or WASM is unavailable the example shows an explicit initialization error — it never silently falls back to HTML rendering.
